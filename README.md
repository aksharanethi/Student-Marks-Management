Student Marks Management System

A beginner-friendly C programming project that manages student marks and displays their academic results.

About the Project

This project accepts marks for 3 students across 3 subjects and calculates their total marks, average, and pass/fail status.

It was created as a beginner project to practise fundamental C programming concepts.

Features

- Accepts marks for 3 students in 3 subjects.
- Validates marks within the range of 0–100.
- Calculates total marks for each student.
- Calculates average marks.
- Checks pass/fail status.
- Displays results in a formatted table.

Technologies Used

- C Programming
- GCC Compiler

Concepts Practised

- 2D Arrays
- Nested Loops
- Do-while Loop
- If-else Statements
- Input Validation
- Basic Arithmetic Operations

How to Run

1. Download or clone this repository.
2. Open the project in a C compiler or IDE.
3. Compile the program:

gcc main.c -o main

4. Run the program:

./main
